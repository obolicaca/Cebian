Use this skill when asked to turn open webpages into a reusable Skill.
Use the tab IDs for pages explicitly selected by the user. Call
`package_browser_tabs` with these IDs and the desired lowercase hyphenated skill
name. If the user has not identified the pages, ask which open tabs to package.
Share the exact artifact Markdown link returned by the tool. The archive can be
downloaded and imported from Cebian Settings → Skills.
