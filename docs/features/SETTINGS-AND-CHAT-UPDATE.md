# 设置与对话交互更新

## 文件管理

- **技能**。顶层目录可勾选。顶部菜单和右键菜单支持批量导出与删除。勾选优先决定批量操作范围，删除前显示待删除项。导出为 ZIP，并在保存对话框中选择文件名和路径。
- **创建目录与重命名**。技能页在明确指定父目录时创建子目录，空白处的操作以根目录为目标。重命名可用 Esc 或点击编辑框外取消。
- **提示词与记忆**。两个页面共用 `MarkdownFileManager`。单击文件打开编辑器，复选框控制批量操作范围。顶部菜单支持导入、导出、导出全部、删除和删除全部。右键菜单支持新建、导出、重命名和删除。导出全部和删除全部涵盖搜索结果以外的文件。
- **Markdown 导入与导出**。提示词和记忆均可导入 `.md` 或导出的 ZIP。单条导出为 Markdown，多条或全部导出为 ZIP。导入发生冲突时默认跳过，可选择覆盖或使用新文件名。提示词同时检查文件名和 `/` 菜单名称，记忆按文件名检查冲突。

## 对话与历史记录

- 历史记录菜单可将单段对话复制为 Markdown 或通过保存对话框下载。已引用的历史对话在引用菜单中显示勾选标记。
- 从对话进入设置再返回时，保留输入中的草稿及引用。
- 对话输入区的引用、工具菜单主文字及相关搜索框使用统一的对话字体设置。引用简介显示在标签上方，普通文件先显示摘要再显示文件名，图片只显示文件名，两种文件名共用排版样式。

## 验证

在独立 Chrome 配置中打开扩展。对提示词和记忆分别导入两个测试文件，验证单击编辑、单条与批量导出、ZIP 重新导入时的冲突处理，以及批量删除和全部删除的确认范围。自动化验证使用模拟保存对话框，删除测试停在确认环节。
